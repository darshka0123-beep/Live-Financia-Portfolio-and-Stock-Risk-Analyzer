# Live Financial Portfolio and Stock Risk Analyzer
An easy to use web dashboard that helps you analyze stocks and track portfolio risk in real time. It calculates key stock metrics, shows interactive charts, checks news sentiment, finds the best portfolio weights, and runs future price simulations.

# How I built this
I built this using a mix of Python and finance tutorials on Youtube. I used claude for assistance occasionally when I didn't understand a certain topic well enough or if I really could not find the bug.

# Languages and tools used
Python, Streamlit, yfinance, pandas & numpy, Plotly, matplotlib, seaborn, scipy, nltk

# What I learned
As someone who is currently studying for DECA and is learning a lot more about finance, I wanted to combine my knowledge about finance with code. This project isn't affiliated with DECA or school, I just applied knowledge learned from it to this project. I learned about stock and risk math, finance terms, interactive charts, portfolio optimization, monte carlo simulations, and more about session memory. 

# Challenges 
Clicking buttons kept resetting the variables which broke the exports. Using session state helped fix that. 
Ran into small syntax bugs. I used claude occasionally when I really couldn't find it but for the most part, I could recheck and read the errors and figure out the bugs.
